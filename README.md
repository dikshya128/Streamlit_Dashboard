# 📊 Superstore Sales & Profit Dashboard

An interactive business intelligence dashboard built with **Streamlit**, **Pandas**, and **Plotly** for analyzing sales performance, profitability trends, customer segments, and regional performance using the Superstore dataset.

---

## 📌 Project Overview

This dashboard provides an interactive environment for exploring and analyzing retail business data. Users can filter data dynamically and gain insights through a variety of visualizations including pie charts, bar charts, treemaps, time-series analysis, and correlation plots.

The application is designed to support data-driven decision making by allowing users to investigate sales and profit performance across multiple business dimensions.

---

## 🎯 Key Features

### 📅 Date Range Filtering

* Select custom start and end dates.
* Analyze business performance within a specific time period.

### 🌎 Geographic Filtering

Interactive sidebar filters allow users to drill down by:

* Region
* State
* City

---

## 📈 Dashboard Visualizations

### Sales Analysis

* Sales by Category
* Sales by Region
* Sales by Sub-Category
* Sales Time-Series Trends

### Profit Analysis

* Profit by Category
* Profit by Region
* Profit by Sub-Category
* Profit Time-Series Trends

### Business Hierarchy Analysis

* Treemap visualization showing:

  * Region
  * Category
  * Sub-Category

### Customer Segment Analysis

* Sales by Segment
* Profit by Segment

### Relationship Analysis

Scatter plots for identifying business patterns:

* Sales vs Profit
* Quantity vs Discount

## 🚀 Running the Application

1. Clone the Repository

2. Install Dependencies from requirements.txt

3. Launch Streamlit using command : streamlit run streamlit_app.py
